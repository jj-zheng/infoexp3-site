Docker チートシート

目的Command
Image builddocker build -t miniboard .
Container rundocker run --rm -p 5000:5000 miniboard
実行中docker ps
Image一覧docker images
停止Ctrl+C または docker stop <name>

よくある問題

変更が反映されない： Imageをrebuildしたか確認。
URLが開けない： Flaskが0.0.0.0:5000でlistenしているか、PORTSを確認。
port already in use： 古いprocess/containerを停止。
