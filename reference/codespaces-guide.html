GitHub Codespaces ガイド

第0回では開発環境の確認に使用し、第3回ではTeam LeaderがWeb Appの一時公開に使用します。

第0回：開発環境を作成

  1. Team Leaderのrepositoryを開く
  2. Code → Codespaces → Create codespace
  3. VS Codeが開いたらTerminalで確認
python --version
git --version
docker --version
docker run --rm hello-world

Web Appを開く

python app.py

下部の「ポート / PORTS」タブを開き、MiniBoard (5000) の転送されたアドレスをブラウザで開きます。Terminalに表示される 127.0.0.1:5000 や 10.x.x.x:5000 をMacのブラウザへ直接入力する必要はありません。

第0回：Port 5000の表示範囲は Private のまま使用します。

第3回：他チームへ共有

5000 → Port Visibility → Public。PublicにするとURLを知る人は認証なしでアクセスできます。

授業用の一時公開です。個人情報や秘密情報を入力しないこと。

終了

PublicをPrivateへ戻し、processを止め、CodespaceをStopします。
