情報科学演習III

Webアプリケーション開発

Dockerで動かし、HTTP/APIでつなぎ、SQLiteに残し、URLで他のユーザに届ける。情報科学演習IIで経験したGit/GitHub・PR・レビュー・AI支援開発を、複数要素からなるWebシステムの統合へ発展させます。

第0回 準備する ↓ 第1回 動かす Docker / Container / Web Server ↓ 第2回 つなぐ Frontend / Backend / HTTP / REST API ↓ 第3回 残す・公開する SQLite / CRUD / Codespaces / Web App Festival
📢 演習資料について： 第0回「環境構築・事前準備」は、各グループのWebアプリケーション開発が始まる前に完了してください。第1回〜第3回の資料は現在準備・調整中であり、授業内容に合わせて更新する可能性があります。各回の授業前に最新版を確認してください。

到達目標

01

動かす

Dockerfile・Image・Containerの関係を説明し、Webアプリをコンテナで実行できる。

02

つなぐ

Frontend / Backend / HTTP / API の役割と、ブラウザからサーバまでの処理の流れを説明できる。

03

残す

REST/CRUDとSQLiteを用いて、複数ユーザで共有される状態を持つWebアプリを実装できる。

04

届ける

GitHub上の成果をCodespacesで一時公開し、URLを通して他チームに利用してもらえる。

授業構成（各150分）

回テーマ主な内容その日の完成状態
第0回環境構築・事前準備Starter clone / Team Repository / Codespaces / Web App確認Team Repositoryと開発環境の準備が完了

第2回FrontendとBackendをつなぐHTTP, GET/POST, JSON, REST API, fetch投稿が画面に追加できる
第3回DBに残し、公開するSQLite, CRUD, Codespaces public port, Festival他チームが同じアプリを利用できる
IIから引き継ぐもの： Issue → Branch → 実装 → 確認 → Pull Request → Review → Merge。Git/GitHubの操作そのものは再講義せず、Webシステム開発の道具として使います。
