APIとSQLの対応を探す

app.py で次の処理を探す：

GET  /api/messages  → SELECT
POST /api/messages  → INSERT
PUT  /api/messages/<id> → UPDATE

HTTP Requestを受けたFlaskが、必要なSQLを実行する。

最終版をDockerで起動

Team LeaderのCodespaceで、最新コードを確認してから：

docker stop miniboard
docker rm miniboard
docker build -t miniboard .
docker run --name miniboard -p 5000:5000 miniboard

上のstop / rmは同名Containerが存在する場合のみ実行。DBがContainer内にある場合、削除すると以前の投稿も消える。

アプリ名を変更していても、Image / Container名はこの例のままで構いません。
