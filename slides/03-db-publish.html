アプリを終了しても、投稿データを残したい。

Pythonの変数

実行中のメモリに保持。プロセスを終了すると、通常は内容が失われる。

SQLite

SQLiteとは？

SQLiteは、SQLを使ってデータを管理する軽量なDatabase Engineです。

Flask（app.py） → Python sqlite3 → SQLite → data/miniboard.db

専用のDatabase Serverを別に起動する必要がありません。

DB = Path("data/miniboard.db")

Table：messages

投稿1件が、Tableの1行（row）として保存されます。

idnamemessagecreated_at
1Aliceこんにちは！日時
2BobHello!日時

messages Tableの列：id / name / message / created_at

実際の定義は app.py の CREATE TABLE IF NOT EXISTS messages で確認します。

ContainerとDataの寿命

「停止」と「削除」は同じではありません。

stop → start

同じContainerを再起動する。通常、Container内のDBファイルは残る。

rm → run

Containerを作り直す。DBが旧Container内だけにあれば失われる。

注意：Volume / Bind Mountで外部に保存している場合は異なります。ここでは削除操作を実行しません。
