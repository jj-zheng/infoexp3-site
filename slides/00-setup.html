2Team LeaderのGitHubにRepositoryを作成する

この操作はTeam Leaderが行います。

New repository Repository name infoexp3-teamXX Visibility Public ☐ Add a README file ☐ Add .gitignore ☐ Choose a license
空のRepositoryを作成してください。
READMEなどは追加しません。

このRepositoryが、これからのチーム開発の中心になります。

← → キーで移動

Before

local repository │ └─ origin ↓ jj-zheng/ infoexp3-webapp-starter

After

local repository │ └─ origin ↓ Team Leader/ infoexp3-teamXX
# ① 現在の接続先を確認
git remote -v

# ② 教員Starterへのoriginを外し、Team Repositoryへつなぎ替える
git remote remove origin
git remote add origin https://github.com/<TEAM-LEADER>/infoexp3-teamXX.git

# ③ Team Repositoryへpush
git push -u origin main

# ④ もう一度確認
git remote -v
最後の git remote -v がTeam Leaderの infoexp3-teamXX を指していればOKです。
